✖ Flaws in Conventional Web Calculators
  • Critical Security Vulnerability: Many web implementations evaluate raw math strings through JavaScript eval(), enabling code injection.
  • Broken Operator Hierarchy: Naive linear parsers execute left-to-right, botching PEMDAS rules and unary negation (e.g. failing on -5^2 vs (-5)^2).
  • Lifeless Touch Experience: Flat HTML buttons lack auditory and physical tactile response, causing frequent unnoticed mis-taps.
  • No Historical Context: Refreshing the browser flushes all previous work, with zero calculation audit tape or constants reference sheet.

SYSTEM ARCHITECTURE
Processing Pipeline & Component Interconnect Data Flow
Stage 1: Lexical Tokenizer

Scans raw character stream. Resolves numbers, constants (π, e), functions (sin, log), and flags contextual unary minus.

Stage 2: Shunting-Yard

Applies Dijkstra's algorithm. Orders tokens into Reverse Polish Notation (RPN) using precedence & associativity tables.

Stage 3: Stack Evaluator

Pops operands into accumulator stack. Executes arithmetic, applies DEG/RAD conversions, and traps mathematical domain faults.

Stage 4: Paint & Sound Bus

Updates LCD annunciators, appends paper tape item to storage, and triggers Web Audio acoustic impulse response.

Engine State Architecture (engine.ts)
  • Linear O(N) evaluation avoids stack overflow on arbitrarily large formulas.
  • Pure TypeScript class with zero DOM dependencies—100% testable in headless node/CI.
  • Deg/Rad angle conversion: θ_rad = θ_deg × (π / 180).
  • Dynamic precision formatter prevents IEEE-754 floating-point visual clutter (e.g. 0.1 + 0.2 = 0.3).
UI Component Topology (React 19)
  • App.tsx: Orchestrates state machine, hotkey interceptors, and audio synthesis.
  • Display.tsx: Dynamic auto-scaling typography and dual-power solar frame.
  • Keypad.tsx: 36 tactile keycaps with 2nd mode register shifts.
  • HistoryPanel.tsx: Real-time paper tape with granular deletion and 1-click restore.

Unary Negation Resolution Logic

Differentiating binary subtraction a - b from negative numbers -x without ambiguous syntax:

  • At Start: -5 is parsed as neg 5
  • Post-Operator: 3 * -4 becomes 3 * (neg 4)
  • Post-Parenthesis: 2 / (-8) becomes 2 / (neg 8)
Domain Traps Guarded:
  • x / 0 → Trapped as "Divide by zero"
  • √(-x) → Trapped as "√ of negative number"
  • ln(0) → Trapped as "Non-positive number"
  • 3.5! → Trapped as "Integer required"

5-Key Memory Architecture
  • MC (Memory Clear): Resets memory register to 0 and clears the LCD 'M' indicator.
  • MR (Memory Recall): Injects current stored register value into expression.
  • M+ / M- (Accumulate): Evaluates current LCD display and adds/subtracts from memory register.
  • MS (Memory Store): Stores evaluated result directly into dedicated memory slot.
